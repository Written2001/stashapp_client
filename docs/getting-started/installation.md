# Installation

Install the latest release from PyPI:

```bash
python -m pip install stashapp-client
```

The package supports Python 3.10 and newer.

For a checkout used in development:

```bash
python -m pip install -e '.[dev]'
```

To build or preview the documentation locally:

```bash
python -m pip install -e '.[docs]'
mkdocs serve
```

The command starts a local preview server and reloads pages as they change.
